# AirPods Color Shop
Простой учебный сайт  по продаже наушников разных цветов для портфолио.  
Можно менять цвета, смотреть модели и видеть изменения на странице.  
---
Проект сделан для практики: HTML, CSS, JS и TypeScript.  
Добавлены базовые эффекты и декор для красивого вида сайта.
